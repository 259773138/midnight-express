# 午夜列车 · Midnight Express

一款十回合、可重复游玩的中文悬疑推理网页游戏。根据《午夜列车》完整游戏设计文档实现的 1.0 版本。

## 特性

- 每局随机凶手、动机、关键线索与干扰线索
- 8 名拥有独立秘密、信任和压力状态的 NPC
- 询问、偷听、搜查、出示证据、跟踪、指认完整行动系统
- NPC 回合间自主移动与反应
- 4 节可探索车厢、10 回合限制、完整结算与评级
- 本地自动存档、响应式手机/桌面界面
- 内置离线叙事引擎，无需 API 即可完整游戏
- Web Audio 实时合成的悬疑氛围音乐、列车节奏与线索音效
- 车厢、座椅、窗景和动态人物像素画场景
- 三阶段“调查员直觉”提示模块，卡关时提供递进式线索
- 可选 OpenAI-compatible API，用于自由问答及每局原创案件生成

## 游玩

直接打开 `index.html`，或访问 GitHub Pages。

> 注意：API 密钥如在设置中填写，仅存储于当前浏览器的 localStorage。纯前端应用无法安全隐藏第三方 API 密钥，建议使用限额密钥或自建代理。

## 技术

原生 HTML / CSS / JavaScript，无构建步骤、无运行依赖。
